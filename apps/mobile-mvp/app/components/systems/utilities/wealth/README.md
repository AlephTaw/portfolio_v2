# Wealth

Three achievement-linked tools, in order: Daily Earning Quota, Debt Repayment, and Cover Monthly Expenses. Each achievement’s eye toggles its tool; double-click reveals and focuses it. Visible tools are always expanded.

Earnings support per-date quotas and receipt records. Debt starts at $50,000 with editable principal and dated repayments. Monthly expenses retain the existing analysis, bill editor, and funding calendar. Earnings and repayments are separate logs, never automatically added to bill funding.

The plan and trackers save under separate mobile-mvp browser storage keys. Shared muted Wealth accents, controls and transparent content surfaces preserve this app’s design system. Other category apps and the source wealth-app are unchanged.
