# Steven Wilcox CV

Single-page public CV and work presentation built with Next App Router semantics
on top of Vinext, Vite, and a Cloudflare Workers runtime.

## Stack

- Next.js App Router
- Vinext
- Vite
- Cloudflare Workers
- Tailwind CSS
- Framer Motion
- Lenis
